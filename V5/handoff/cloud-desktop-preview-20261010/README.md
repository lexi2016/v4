# V5原界面：只读云端PARTIAL预览

Linux/macOS Python3.10+标准库即可运行。此包是已运行界面和不可变响应的可移植快照，不是新采集或全量业务部署；无凭据、原始行情、公告正文、账户、订单或采集器。

在独立空目录解包后执行：

    python3 serve.py --port 18896

然后在**运行该命令的同一台桌面**浏览器打开：

    http://127.0.0.1:18896/manager-selection/?date=20261012

只绑定loopback，三个端口18896/18897/18898须空闲，可改--port，另两端口自动+1/+2。Ctrl-C仅停止本次子进程。若有端口冲突请选新端口，不停旧服务。不要开放公网或关闭Host/Origin规则。
