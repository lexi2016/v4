唯一运行角色 CODEX_MAC。原 A identity 为 `aa4de242906913e5a369b93bc304bdde64ded10de77f2d3fe67bdf20203f5fa2`。基线代码 `032e197750fd0a98d4da8ca5010ec0ede5ae0d90` 保留。主控将双容器状态保留为 NOT_TESTED，单 Mac 验收使用本机 Unix socket 与 SQLite。

## 存储和进程边界

- 正式运行只读原 A、原 PRELAUNCH、官方六包和原折。初始化从全验原 A 的历史证明导入原 identity、14 条事件、7 个开始令牌、F1 失败、F2/F3 完成和原有花费。历史导入与新运行事件分账。预处理 3/4、模型 2/4、API 2/3、历史失败 1。
- Mac 的正式权威目录为 `~/.local/state/p515/r1`。该目录所有者权限独占，正式服务持有单例锁，客户端通过 socket 进行只读查询及送签名请求。数据库与 fence 由服务原子推进。Mac 登录所有者和操作系统受信，任意同 UID 本地代码不在隔离威胁模型内。旧研究文件只保全，不从冻结工作树运行旧训练器。
- 真实公钥与原旧写端停用凭证由 CHATGPT_MASTER 从已认证的交接线提供。无信任根时导入状态可只读核验，任何正式预留在 START 前拒绝。正式键登记为本地管理员的单次操作，禁止从客户端 RPC 发放或变更正式根。
- SQLite 整个 F1 单元先预留，历史 START 不删除。每阶段在实际调用前持久记账。未知事务按同一授权 ID 或 transaction ID 查询，禁止自动重进。崩溃、网络关闭和输出校验失败均保留已耗用预算证据。

## 模式和口径

`CHECK_ONLY` 读原账。测试从独立临时目录使用 `SYNTHETIC_EXECUTION`。正式模式 `AUTHORIZED_EXECUTION` 仅接受带 Ed25519 签名的 F1_RETRY 授权和同身份封装文件。

F1_RETRY 的 AUTH-01 只允许原总额度 4／4／3，单次增加 1／1／1，成功后累计 4／3／3。没有签发件和最终封存前禁止启动。预留仍可通过授权号查询，不能无清晰结果重新提交。

本版本正式 FINAL_DEV 保持拒绝。只有 F1 的完成、全部原行和交易审计通过之后，才能提交单独 AUTH-02 申请。AUTH-02 只把预处理上限从 4 调到 5，模型和 API 上限仍为 4、3。FINAL_DEV 预测 0，F1/F2/F3 不重跑。

## 复现与回退

复用固定版本 F1 输入、官方模型与预处理方程。通过 PID、进程启动日志、socket 路径、inode、存储 fingerprint 和精确候选代码 SHA 共同核验。临时测试用合成权限和隔离数据库，真实调用计数 0。上线/续跑前保持一个受监督进程，不加载 Docker 或定时任务。

测试可以中止新候选进程，保留已落账的权威和所有历史。启动后的未知事务按原笔查询。回退时禁用候选入口，保留不到账的故障证据、历史资产和 V8 旧件，禁止用旧脚本还原余额。
