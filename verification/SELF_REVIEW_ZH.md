# 复核范围及限制

本轮执行了源码差异复核、离线故障复现/回归、真实本机双进程争用与退出恢复、原包字节核验和纯函数 AST 对照。没有可用的独立第二审查执行者；不能称“第二人/独立代理审查通过”。

复核中额外发现并修复：通用 byte writer 误伤研究标签；研究标签投影名称冲突可覆盖嵌套数据；job_id 可重绑定到另一输入；未知 PID 探测错误被当作死亡；布尔 PID；业务 TimeoutError 被误报为锁超时；迁移 writer 后必须继续拒绝 Windows 盘符路径。对应负向日志在证据包。

不据本轮结论放行：原有 146 失败、27 收集错误和 3 跳过均保留；实际 Python3.14/macOS、真实来源、浏览器、进程级资源终止、正式路径政策、所有旧锁/孤儿恢复分支及包外旧磁盘格式消费者仍未完成验证。

新提交协议只为参与该协议的本地进程提供一致结果可见性；SHA-256 是完整性校验，不是防恶意篡改签名。旧格式读取也不是新提交协议的认证。内核锁依赖私有本机目录与协作 writer，不能等同分布式或敌对目录所有者保证。

正式验收应继续保留 RESEARCH_ONLY/WATCH_ONLY、安全旗、exact-date 和证据失败关闭；不得以删测试、改历史 SHA 或放宽正式根来完成“验收”。
