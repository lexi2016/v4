The manager scheduler is a separate, running LaunchAgent with a one-minute WorkbenchHook. It generated the 2026-10-20 next-day draft on Friday 2026-10-16 at 17:39 HKT, before the Friday US session closed. Its current tick only handles HK 09:25, changed stage runs, and a once-per-source-day 16:30 next-day plan. On Saturday the HK calendar returns `NOT_APPLICABLE`; no event from the US digest reopens or refreshes the existing next-day draft after its cursor is set. The US digest workload itself only invokes `ops.us_market_digest`; it does not invoke manager selection or a Feishu delivery path. A displayed plan, a local payload, and an actual notification are distinct outcomes.

## Date and input contract

- Friday US session: `20261016`, full NYSE session. The local US-slot resolver maps Shanghai `20261017 04:15` to `POST_CLOSE / us_session_date=20261016` (DST-aware `America/New_York` → `Asia/Shanghai`).
- HK target: `20261020`. HKEX lists Monday 2026-10-19 as a no-trading holiday (the day following Chung Yeung Festival), so 10-19 is not a valid HK selection date. Sources: [NYSE 2026 Trading Calendar](https://www.nyse.com/publicdocs/nyse/ICE_NYSE_2026_Yearly_Trading_Calendar.pdf), [HKEX 2026 Securities Market Holiday Schedule](https://www.hkex.com.hk/-/media/HKEX-Market/Services/Circulars-and-Notices/Participant-and-Members-Circulars/SEHK/2025/ce_SEHK_CT_075_2025.pdf).
- Current `run_us_market_slot` date calculation for that 04:15 slot returns `scheduled_date=business_date=target_date=20261017`. The workload catalog uses `BUSINESS_DATE` for both signal and target roles and passes that business date to `ops.us_market_digest`; it does not bind the capture to the next HK session. Current manager input binding prefers an artifact under `target_date` and otherwise tries the US session-date folder, then validates the capture session. The contract therefore needs an explicit exact mapping from US session `20261016` to HK target `20261020` while preserving `trade_date`, `us_session_date`, cutoff, manifest and SHA as separate fields.
