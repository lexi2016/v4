# 语义复核判例

这些是校准判断的反例与正例，不是固定股票白名单。查看对应原文，并按当前窗口、来源和证据重新判断。

- 智通文章 `1507189`，中国生物制药 `01177`：TQ-A3334 与 Bepirovirsen 的研究摘要将于 AASLD 展示。未来学术展示本身值得作为催化关注；不能写成疗效成功、临床终点达成或药品获批。区分文章发布时间、会议时间与研究结果实际披露时间，并核对原始公告。
- 文章 `1507233`，剑桥科技 `06166`：10月14日新闻转述 Morgan Stanley 对10月8日增持约514.28万股的披露，约5.44亿港元。新闻日不是交易日；原始权益披露文件（DI）未核实前标记待核，不写成10月14日买入。检查实际持有人、交易日、披露日、股数和金融工具。
- 文章 `1506988`，药明康德 `02359`：标题中的“大摩”是 Morgan Stanley 对公司扩建产能的研报观点并维持“增持”评级，不是机构持仓或买入交易。公司扩产事实与券商判断分开记录。Morgan Stanley（大摩/摩根士丹利）和 JPMorgan（小摩/摩根大通）是不同机构。

临床、科研和批文条目须区分计划展示、已披露数据、临床阶段/终点、监管批准及商业销售，不能互相替代。订单、合同和中标要区分已签金额、预计采购、框架额度、条件性部分、收入确认和利润；有金额也不能自动推断利润。

大股东/机构权益披露可能涉及受控实体、衍生工具及好仓或淡仓。只有文件支持时才描述实际交易；未核对原始权益表时保留待核，不能把持仓变动解释为机构自营坚定看多。券商“增持”是评级，不能替代买入记录。公司回购要说明已执行、授权或拟议，避免把不同状态混为一谈。

同一事件同时有利有弊时并列两面，例如收入增长伴随指引下调、订单规模大但利润率未知、获批但尚未销售。正负方向、关注级别和研究理由必须能回到证据；不按涨幅、热度或人为分值做筛选。
