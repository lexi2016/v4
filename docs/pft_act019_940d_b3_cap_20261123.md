# ACT-019 保守 T+3 的 B3 单席实验

使用 ACT-015 的同一 940 日和保守 T+3 规则。观察期从 2023-01-03 至 2026-11-20，三条对照曲线和成交直接复用 ACT-018，实际拟合为零。

原 HYBRID 先按原始分数、证券代码及轨道排序，按 D 与证券去重。变体只限制每个信号日最多入选一个 B3，继续沿原顺序取其他合格证券至多三只。B1/B2 保留年度原始 Q80。日内开盘入场失败后沿用原预算与现金规则。回放保持 D+1 开盘、D+3 计划收盘，原宽度开关、黄线、锚位、移动止盈和费用。

使用项目解释器从仓库根运行 `python -m ops.pft_act019_b3_cap --help`。所需候选、对照账本和风险按 ACT-018 或 ACT-015 封存绑定，只读一次新选中证券的 V4 执行行情。正式研究产物包括选中信号、成交账本、净值、绩效和区间归因。按实际入场年度统计已成交占比，按同证券同 D 核对六个原错例。
