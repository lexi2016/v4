## 方案

### 1. 把缺口按五类拆开核验

沿用 V4 现有目录和材料链路，不另建 producer 或数据底板。逐一核验：

1. **身份与代码：** 公司法定/常用名称、上市主体、股票代码及名称沿革。
2. **港股通有效期：** 标的在指定日期是否属于港股通标的，并保留生效区间和官方来源；当前名单不能替代历史名单。
3. **主营分类：** 按公司披露的业务、收入和利润驱动归类，不以宽泛行业相似代替主营证据。
4. **关系证据与经济传导：** 记录美港公司关系的具体类别、可追溯证据及从美股事件到港股经营或价格的传导链；ETF 或泛同行关系不能覆盖直接关系缺口。
5. **运行消费：** 核实既有研究目录中的材料如何进入实际研究结果，并记录产物、版本、日期和消费者之间的对应关系。

映射率和推荐率必须分开报告。存在映射不代表存在足够证据推荐；推荐数量也不能反推映射完整度。

### 2. 以高鑫零售 06808 做第一只单例

先核对证券身份、代码和港股通有效期，再依据正式披露研究主营收入与利润驱动。对潜在美股关系逐项标明关系类别、证据和经济传导；美股催化与港股公司自身催化按事件时间及首次可用时间分开记录。每项判断都要给出反证、失效条件和未知项，并将结论明确归为推荐、风险、观察或材料不足。

不得把 WMT 下跌自动解释成高鑫利空，也不得因此自动判定高鑫有机会。事后上涨不能修改当时规则，也不能证明在当时信息集下本应推荐。

### 3. 建立有截止时间的点名研究队列

每条点名记录至少包括点名时间、目标交易日、问题、负责人、截止时间和材料/结论版本。截点前的点名优先处理；到期必须给出结论或结构化缺口、缺少来源及后续所需材料。仅有观察状态或生成了一段文字不算完成。被点名只代表需要研究，不自动转成推荐。

### 4. 固定每日结果的分区和准入

每日重点研究推荐为 0 至 5 只；重点风险单列；背景观察折叠展示并明确不计入推荐。准入前先核对日期、身份、来源和范围，再检查当日有效催化、可解释的影响、相互矛盾的信息和证据缺口。通过准入的对象按证据强度、关系直接性、信息新鲜度及风险排序。

每张推荐卡都要列明正向与反向情景、来源、催化时间、失效条件、未知项和材料版本。无法通过准入的对象留在观察、风险或材料不足区；允许当日推荐为 0。

### 5. 分批扩展样本

- **第一批：** 高鑫零售 06808 单例。
- **第二批：** 禾赛 02525（核对与候选美股主体是否同一发行人）、广和 00638（核对具体业务链）、毛戈平 01318（核对主营分类）、深演智能 02947 与 02723（核对主体身份及代码连续性）。上述名称、代码和关系均须先用来源核对，不将候选描述当作已验证事实。
- **第三批：** 机械盘点 V4 现有目录，以点名任务、有效催化和研究价值排序；先复用已有材料，不做全市场 LLM 重跑。

第一只未通过验收时不扩量。每批的扩大范围应另有结果和裁决依据。

### 6. 硬验收与计划时点

验收至少满足以下条件：

1. 核心事实均有来源和时间信息；未知或无法确定首次可用时间的事实明确标记 `CANNOT_CONFIRM`。
2. 每个研究问题都有答案或结构化缺口。
3. 背景观察混入推荐数为 0，推荐数不超过 5。
4. 到期点名任务有结论或结构化缺口的比例为 100%。
5. 产物、API 与 UI 上展示的版本和日期一致；需要独立 Reviewer 对冻结范围验收。
6. 拟议流程截点为北京时间（`Asia/Shanghai`）08:30，08:45 输出。参数尚未批准前不得建立或修改调度。
7. 连续 5 个港股交易日只用于检查流程是否按约定工作，不证明 alpha，也不构成收益验证。

本方案不授权或包含模型替换、收益回测和交易门禁调整；研究结果保持研究用途，不构成下单授权。
