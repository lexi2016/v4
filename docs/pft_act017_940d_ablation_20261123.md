# ACT-017 ACT-015 保守 T+3 的 940 日归因

用 ACT-015 已封存的 940 日样本、预测和保守 T+3 交易规则，检查扩展三分位与 HYBRID 路由的单独及共同影响。样本外 2026 截至 11 月 20 日。实际 FIT 为零。

| 配置 | 择时 | 选股评分 |
|---|---|---|
| 基线 | 原保守 | 原 RF |
| 仅择时 | 扩展三分位 | 原 RF |
| 仅路由 | 原保守 | HYBRID |
| 两者 | 扩展三分位 | HYBRID |

四组统一每日最多 3 只、同一 D+1 开盘和 D+3 计划收盘、相同费用、停牌与一字板处理、黄色与关键 K 破位、移动止盈和弱市退出。扩展三分位只改变当日入场档位和仓位上限，沿用原保守引擎的预算及退出流程。中档的 50% 上限因既有持仓占用而减少新仓空间，既有仓位依原保护和期限管理。

HYBRID 沿用 ACT-016 的本地分轨门槛和分数比较。B1/B2 过年度 Q80 后用 RF 分，B3 用门控后 S 概率 × B 概率。名单保持固定的独立 Top 3，选择后才执行择时。报告另按相同候选池计算 Q80 和 B3 分数换尺度对入选结构的影响。

使用项目绝对解释器在源码根执行 `python -m ops.pft_act017_ablation --help` 核对入口。四组持仓回放公用一次 V4 Reader 读取，执行行情保留在进程内存中。检查封存排名、940 日基线精确一致性、完整组合净值、成交账本、年度和回撤区间逐笔归因。归因按同一笔持仓在起点和终点的扣费估值变化，按组合净值分母折算。样本为当前 V4 前复权快照，历史逐日版本 CANNOT_CONFIRM。

范围为 `RESEARCH_ONLY=true`、`production_allowed=false`、`buy_gate_updated=false`、`orders_sent=false`。
