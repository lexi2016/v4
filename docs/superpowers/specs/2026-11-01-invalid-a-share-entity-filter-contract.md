# 非法 A 股实体的读取侧过滤合同

- 日期:2026-11-01
- 状态:**设计草案,未实施**
- 起因:`a_share_research_recommendation_pool` 里出现 `code=261029` / `symbol=A.261029`
  (实体名显示为申昊科技),`261029` 实为日期 2026-10-29。阶段选股因此把
  `SZ.261029` 计入隔离,是 `522/532` 覆盖缺口的一部分。

## 1. 目标与非目标

**目标**:非法实体不再作为有效 A 股出现在消费面;不篡改已发布证据、不删除源文章、
不改写历史计数。

**非目标**:
- 不重写已发布的池产物(存储写一次,`materialize` 拒绝覆写)。
- 不回溯修改已保存的阶段结果。
- 不用"过滤后仍声称是原始完整产物"的说法。

## 2. 三个消费边界(必须分别处理)

| # | 消费面 | 读取路径 | 过滤该放在哪 | 现状 |
| --- | --- | --- | --- | --- |
| 1 | 预选池 API | `PreselectionPoolStore.read_all*` → 投影 | 原始 SHA 校验之后的投影层 | 未实现 |
| 2 | 研报决策台 | `domains/research.py` 直接读 `stock_research_daily[].stock_code` 建 `stock_pool` | 该模块自己的投影 | 未实现 |
| 3 | 已保存的阶段结果 | `stage_center` 选择产物(`selection_recovery.markets.A_SHARE.missing_symbols`) | 不重算,原样展示并标注 | 保持原样 |

**三者互不覆盖**:过滤预选池不会让决策台那一行消失;已保存的阶段结果也不会被重算。
任何"改一处就全解决"的说法都是错的。

## 3. 过滤位置的硬约束

1. **必须在原始 SHA 校验之后**。先按存储内容验摘要,再过滤;不得对过滤后的内容算验证摘要。
2. **不得静默替换**。返回值需同时携带:
   - `original_row_count`(原始行数,未过滤)
   - `effective_row_count`(有效行数)
   - `quarantined_row_count`(被隔离行数)
   - `quarantined[]`(每条:原始 code、原始名、原因、规则版本)
   - `filter_rule_version`(例如 `a_share_code.v1`)
3. **不得让一条坏行全局阻断**。单行非法只隔离该行;只有完整性错误(摘要不符、
   结构不符)才允许整池拒读。
4. **既有口径不变**:原排名 `pool_rank`、原 `article_count`、原 `pool_score`
   一律保留原值,不为过滤后重新编号。要排名请显式请求"有效排序",并说明口径。

## 4. 判定规则

以 `contracts/a_share_code.py` 为准:

- 6 位数字,且两位前缀属于真实存在的号段(股票 `00/30/60/68/92`;
  同池基金 ETF `15/16/18/51/52/56/58`)。
- 必须独立成词:前后都不能紧邻数字(`6005191` 不是代码)。
- 多 token 文本逐个尝试,任一合法即为该行的代码(`261029 600519` → `A.600519`)。
- 无合法代码时返回空,**不发明实体**。

规则变更需升 `filter_rule_version`,并在隔离记录里写明用的是哪一版。

## 5. 审计记录

- 被隔离的实体必须留档:原始 code、原始名、来源池、日期、原因、规则版本、
  发现时间。**不删除源文章、不删池行、不改历史计数。**
- 三个消费面共用同一份隔离记录,避免各写一份口径。

## 6. 与存储写一次的关系

已发布池不能被 `materialize` 覆写(实测 `conflicting preselection-pool materialization`),
现有接口里 `refresh_verified_hk_resolution` 仅限 HK,`recover_expected_missing`
只处理 `EXPECTED_MISSING` 占位符。

因此**修正已发布产物只有两条路**,都需要单独设计、单独授权:

1. **追加纠正版本 + CAS 切换引用**:旧版本保留可查,新版本是新证据,引用切换用
   比较并交换;读取方按引用解析。当前无现成接口。
2. **读取侧过滤**(本文档):证据不动,消费面不显示,隔离留痕。

本批选择第 2 条。

## 7. 验收

- 三个消费面各自有测试:合法行不受影响、非法行被隔离而非丢弃、计数三件套齐全。
- 预选池:`original_row_count` 与磁盘产物的行数一致;`effective + quarantined = original`。
- 决策台:非法实体不再出现在股票层,但审计记录可查。
- 阶段结果:不重算,展示层标注"含 N 条历史非法实体记录"。
- 全量测试与基线比对方式见 `2026-11-01-v4-phase3-globals-dependency-graph.md`
  §10 的固定命令与诊断集合。
