# ACT-018 保守 T+3 分轨百分位回放

用 ACT-015 同一 940 日样本外快照和保守 T+3 回放，比较原 RF、原 HYBRID、百分位 HYBRID。2026 年截至 11 月 20 日，正式冻结模型继续封存，实际拟合为零。

- 原 RF 和原 HYBRID 直接引用 ACT-017 已独审的逐日净值、选中信号和持仓账本。百分位组用相同的 Top 3、严格宽度开关、现金预算、费用、D+1 开盘及 D+3 计划退出，复用原黄线、锚位和移动止盈保护。
- 先按原规则做 S、B 硬门控，B1/B2 保留原始 RF Q80 门槛。跨轨排名时，B1/B2 的 RF 分和 B3 的 S×B 分别由同轨截至前一年度末的分数分布转为百分位。经验中位秩为低于该分数的样本数加一半等分样本数，再除以该轨样本数。并列按证券代码和轨道稳定排序。
- 2022 B1/B2 校准使用 ACT-016 已封存证券隔离样本。B3 沿用对应年度两侧 S 与 B3 权重补算证券隔离分数，2022 种子供 2023 起的阈值和分布使用。2023 起只追加各待评年份之前的封存 OOS 分数。
- 对照 ACT-017 六个负例时按证券和 D 键对齐。原保守择时已拦截的席位与百分位路由换出的席位分别记录。若证券留在同日名单中，核对仓位和执行净收益。

用项目绝对解释器从仓库根运行 `python -m ops.pft_act018_b3_calibrate --help` 和 `python -m ops.pft_act018_percentile --help`。只在内存读取执行所需的 V4 行情。新分轨行为、因果校准和原对照复用通过针对性测试后运行。
