# 美股因子公开研究与当前实现差距（2026-10-13）

## 结论
当前程序是固定33个美股来源的已审核公司关系观察筛选。21个ETF没有HK公司关系，因此无法产出股票；这是现有映射覆盖的结构性限制，不等于ETF不能用作因子。应分别研究市场、行业和公司经济联系，不能把三者都当成“合作关系+美股上涨”。

## 查到的原始研究与公开实现
|方法|实际来源与做法|可借鉴范围与限制|
|---|---|---|
|跨市场领先收益|Rapach、Strauss、Zhou（2013），用滞后美国月度市场收益预测其他工业化国家市场，并估计信息扩散模型。https://onlinelibrary.wiley.com/doi/abs/10.1111/jofi.12041 |说明领先变量应当实证估计；月度市场结果不证明港股日内股票Alpha。|

|客户动量|Cohen、Frazzini（2008），以事前披露的重要客户—供应商关系，研究客户历史收益对供应商后续收益的预测。https://pages.stern.nyu.edu/~afrazzin/pdf/Economic%20Links%20and%20Predictable%20Returns%20-%20Cohen%20and%20Frazzini.pdf |关系方向、经济重要性及当时可得性很关键；历史技术采用、未来计划、间接平台合作不能等同重要客户收入暴露。论文是美国样本、月度策略。|
|海外经营暴露|Xing Huang（2013工作论文），以海外经营所在国家的对应行业收益衡量外国经营信息，控制本国和全球行业动量。https://broad.msu.edu/app/uploads/2019/02/Thinking-Outside-the-Borders-V2.2_Xing-Huang.pdf |提示按真实业务暴露分配外部信号；不是只凭同属热门概念。研究对象和频率不能直接移植为港股隔夜收益保证。|
|美港非重叠时段|Gannon（2005），美股标普期货隔夜冲击与香港市场波动、成交量传导，使用港股开盘前可观测的美股数据。https://www.sciencedirect.com/science/article/abs/pii/S1057521904001048 |强调非重叠时间对齐；研究波动传导，不等于证明收益方向或可获利选股。|

## 建议研究的最小因子（本报告提出，尚未实施）
1. 行业相对强弱：美国行业ETF收益减去其对美国大盘的历史暴露所解释的收益。暴露只用信号产生前的历史估计。保留连续值及行业内排名，不先硬设涨幅大于零。
2. 港股行业暴露：用已有研究面板中可追溯的行业/主营业务归属，将上述信号赋予相关港股；ETF不要求公司合作关系。粗行业与细主题分开，有明确资料才用细主题。
3. 公司经济联系：保留现有已审核关系，但区分客户、供应商、竞争者、联合设计和历史合作；对传导方向分别验证，不能无条件认为双方同涨。
4. 市场环境：美国大盘信号用于解释共同市场变化，与行业和个股增量信息分开；不把风险暴露直接称为选股Alpha。

示意定义：行业残差信号 = 行业ETF收益 − 历史beta × 美国大盘收益。港股因子 = 截止前确认的行业暴露 × 行业残差信号。该式是可检验候选，不是论文原公式或已验证策略；beta窗口、收益时段、映射细度均需预先冻结。多因子先单项验证，本报告不授权新增综合评分。

## 数据与验收
优先盘点现有研究面板已有的美股/ETF历史、港股历史、行业分类与时间戳。缺字段明确列出，先不引入新producer、行情账户或付费源。
美股收益只能使用港股决策时点之前已结束/已收到的交易时段，处理两地假期及夏令时，不按同一日期字符串机械拼接。
分别评价港股前收盘到开盘、开盘到收盘、后续若干交易日；开盘跳空可预测不等于开盘后可赚。
固定现有候选池与样本，在时间顺序训练/验证和封存区间上比较：当前规则、行业因子、公司关系因子。报告Rank IC、分组差异、覆盖、换手、费用滑点后结果及失效月份；不要以选出更多股票判为成功。
参数或映射未经验证不切换现役规则。美股推荐与超跌推荐继续独立，超跌40%不参与美股因子的门槛。
