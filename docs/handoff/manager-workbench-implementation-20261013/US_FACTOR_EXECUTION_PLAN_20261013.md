## 风险与停止规则

1. 来源/日期/口径不明：仅对应来源保持 CANNOT_CONFIRM，继续其他可核实部分，不另造数据。
2. 历史不足：不拟合不可靠 beta，不换窗口掩盖缺口；走明确的研究候选/前向留样阶段。
3. 映射不足：明确未覆盖，不将概念关键词命中直接升为真实经济暴露。
4. 因子无效：保留失败结果与原基线，不以多选股票或展示成功代替有效性。
5. 共享文件变化：暂停该文件合入，保留其他阶段成果；不回滚他人修改。
6. 需要新来源、账户、额度、外部生产或重大业务范围变化：先列出具体必要性，再请求用户裁决。
