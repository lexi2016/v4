# ACT-015 全 A 股滚动 Walk-Forward 研究

本批使用 V4 冻结行情与 ACT-013 市场宽度产物。2022 年仅供首折训练，2023–2025 是完整样本外交易年度，2026 截至 11 月 20 日。研究回放使用当前前复权面板，历史逐日复权版本 CANNOT_CONFIRM。

从项目根目录使用 `PANEL_PYTHON` 所指的项目解释器，按顺序运行以下阶段。各阶段以清单 SHA 绑定上游。

| 阶段 | 入口 | 保留结果 |
|---|---|---|
| 全量投影 | `ops/pft_act015_project.py` | 来源、日期、证券去重、自然触发、样本与训练标签清单 |
| 滚动拟合 | `ops/pft_act015_fit.py` | 逐折成员、80 份可重载权重、独立证券预测、回放前封存 |
| 预测排序 | `ops/pft_act015_rank.py` | 每日各池前 3 名、因果市场档位、排名封存 |
| 组合回放 | `ops/pft_act015_replay.py` | 连续组合净值、成交账本、年度与合并统计 |

每个外折只用其拟合窗口内另一证券组的标签。历史收益标签到期日不能晚于该折的训练截止日。两个期限及择时消融使用同一排序。信号取 D 日收盘，开仓最早为 D+1 开盘，买卖各扣 7.5 bp 和 12.5 bp，无法成交按方向代理处理。正式冻结纯 S 权重保持封存，本批新权重只服务研究回放。

训练阶段可用 `--resume` 续跑已归档权重。续跑按归属、日期、训练矩阵、数据成员和模型哈希匹配，无法确认的状态保留原失败证据。训练及回放封存后，投影分片可由原输入和代码重建。运行产物保留在本地研究档案，Git 同步源码和针对性测试。

针对性测试由 `pytest` 运行 `tests/test_pft_act015_{project,fit,rank,replay}.py`。本批范围为 `RESEARCH_ONLY=true`、`production_allowed=false`、`buy_gate_updated=false`、`orders_sent=false`。
