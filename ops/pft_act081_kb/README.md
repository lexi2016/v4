# ACT‑081 Phase 1 · 知识库特征与两轨研究

仅供研究。零 FIT、零调参、零训练、PIT=CANNOT_CONFIRM、NO_GO。Phase 1 冻结任务书、P1B 已审底座、72 例排除清单按原字节 SHA-256 验证。源依据为《完美B1图形全文》第 1 页和《十图指南》第 45、77、85 行。任务书优先固定数值门槛。VOL2 行情只读，冻结 V2.1 只读。

## 规则

- 采用 ACT‑080 P1B 的观察日时钟、W/Y、Key K、锚点生命周期、守住锚低、结构 episode、分期和 10 日 purge/embargo。两轨合用 P1B 单一按股 cooldown，严格 `gap > 5`，任何 track、episode 或窗口边界均不重置，拒绝不占下次冷却。
- B1 的资格为 W≥Y、D 收盘≥Y、相对前收涨跌绝对值严格小于 2%、振幅严格小于 4%（300/301/688 严格小于 7%）、激活锚龄 1–45 且 D 收盘不低于锚低、D 量不超过锚点至 D−1 正量峰的 0.50 倍。在 D 确认收复黄线时亦满足 C≥Y，未实际收复时不提前计入。
- B2 复用 P1B B 臂量价启动原式，使用其活动结构与 0–29 锚龄限制。两轨同一股票、同一 D 互斥。B2 仅独立出量级和台账。每轨在同一 P1B `structure_episode_id` 内的首次放行标为 FIRST。估计只使用 B1 FIRST，B2 自身标注不充当 B1 FIRST。
- 阳阴量比使用激活锚点至 D（含）窗口，`(ΣV[C≥O]+1)/(ΣV[C<O]+1)`，单位为一原始量单位。窗口无有效锚点或累计总量为零输出 NA。
- 缩量深度为 `V_D/MAX(V[anchor:D-1])`。取先达到的最大量峰。峰后的 1–3 个观测日一旦看到半量及以下，速度旗标为真，完整三天未达为假。峰为零或未成熟且尚未达到时为 NA。新峰仅影响后续 D。
- 近五日按阴量回吐的观察日计数，上一观察日需有 P1B BREAKOUT 或 VIOLENT Key K，且前一根严格收阳（C>O）。当前为阴线且 C<前收、V≥0.75×前阳量。有效对数不足五且无已观测命中时为 NA。窗口内有命中立即为真。
- 60 日位置为 `C/MIN(L[D-59:D])-1`。完整 60 日且分母及当前 C 为正时计算，≤35% 为 LOW_FIRST_WAVE，≥80% 为 HIGH_RUNUP，其余为 MID。位置是诊断特征。
- 灵魂子集为 B1 FIRST 中阳阴量比≥1.2 且 3/4 警示为明确假。NA 不进入子集。所有规则一次冻结，交易结果只进入事后对照。

## 对照

40 股 Clean OOT 从已通过 P1B 时间隔离的 OOT FIRST 单向筛选，整股隔离钧达。72 例按同股有效交易日完整映射。候选 `D+1..D+20` 与已解盲参考的冻结旧 `D+1..D+10` 区间重叠或触发差绝对值≤10，均移除。两政策使用同一排除规则。V2.1 每原结构取最早 FIRST 后筛原 A 档，该身份来自冻结表。

入场 D+1 open，T+2/5/10/20 observed close，固定双边合计 30 bp。MAE5 用 D+1..D+5 最低 low，标准尾跌 T+2≤−5% 或 MAE5≤−7%，辅尾跌 T+5≤−5%。按成熟分母汇报，保留 UNKNOWN。钧达全史按已发生的完整历史计算，另存的分期结果对 TRAIN/VAL 的退出和 MAE 施加原时间边界。去重叠按同股 D 升序贪心保留不重叠 D+1..D+20 窗；等权结构无额外加权；前三贡献股按 B1 成熟 T+5 汇总净收益降序、代码升序打破平局，向三个政策共同剔除；留一股覆盖全部 40 股并以各政策 T+5 净均值的最小值汇报，不重训。钧达 7 日期精确匹配，命中以当日独立 B1 FIRST 为主要依据，保留原始资格、重复、冷却和失败门槛核对列。

## PNG

严格先切断股票链到 D 日，再从物理前缀计算 W/Y，裁最后 61 根。Y 完整需要 114 日预热，因此最早可绘索引为 173（0 基），显示的 61 根均需正 OHLC。钧达七例逐一保留。Clean OOT B1 FIRST 中取候选 ID 字典序前 20 个符合画窗条件者，选择在事后收益读取之前完成。图像只有顺序排列的 K 线、W、Y、量柱，输入渲染器仅有数值，文件名为匿名 ID，PNG 不含身份或日期文本/元数据。独立索引保留研究复核映射。
