# ACT-082 Stage 2A, authorized SEALED extension

This entry point binds the operator-authorized exceptions to the existing frozen logical Reader, V4 generation, 1,179-code known-exposure manifest, BSE alias crosswalk and completed DEV frame. It excludes literal and alias-equivalent exposures. Historical exposure completeness remains unverified. It allows the local F10-cap and industry snapshot columns, including the actual archived F10 source date. F10 is not relabeled as historical PIT data. Quote projections on both carriers are restricted to trade dates through 2025-09-30. Volatility uses the sample standard deviation of the 20 latest log returns from 21 observed positive closes in the bounded window.

The optional explicit CLI switch records both already-granted exception choices. The only execution path creates a fresh one-shot intent, selects 40 main and 10 heterogeneous canonical issuers, and seals the in-memory mapping with AES-256-GCM. There is no decrypt, open, chart or performance entry point. The access ledger has the owner-only mode, an OS append-only flag and a same-length truncation denial probe. The public aggregate JSON contains no ticker or key locator. The separate on-host key directory has a user-only custody receipt.

This module does not modify the DEV/runtime lock, rerender charts or access future quote dates.
