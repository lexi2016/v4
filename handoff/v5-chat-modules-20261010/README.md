# V5：18个原模块，18个独立Chat

2026-10-10，按用户最新要求组织。原M01—M18编号与P0—P5验收范围不变；先前“第一/第二批”跨模块交付名称停止使用。每个Chat只负责一个原模块，准备好的材料逐份交付。

## 分工及防止相互覆盖

- Chat：读固定原代码、审查对应模块、复用原算法，交具体最小候选、完整修改后文件、精确补丁、前后SHA、针对性测试与Mac落地/回滚步骤。
- 嘻嘻：准备材料、检查模块边界、在Mac应用候选并独立测试，用内置浏览器验收，给原Chat反馈准确问题。
- 每个Chat只能修改自己模块的代码/私有输出/测试；依赖模块仅消费约定接口。跨模块问题用请求单说明路径、字段、理由、兼容性及测试，不直接替其他Chat整文件改写。
- 共享网关、前端、调度、公共合同、发布注册保持单一集成写入者。模块Chat可交精确建议差异；整合前按最新前像核对，避免多个候选相互覆盖。不能为隔离而复制第二套算法或活动数据底板。
- 每份候选都以明确固定版本为输入；其他Chat的新返回不会自动进入基线。嘻嘻整合后反馈新的固定提交与需要更新的最小范围。
- 保留V4与8910，不交易，不扩大安全权限/凭据，不上传Mac私有原始数据。本轮只备文档，没有产品测试或部署。

## 总体验收不变

每个模块分别登记代码接入、真实数据通过、页面可用、自动接续、完整验收。不能用源码存在、静态方法数或合成测试数替代真实通过。

首批仍是13公告、14超跌、15美股三策略真实结果可见，并经18普通API/页面同run读回。四键美股seed只是有限范围，缺源不等于有效空。已有通过证据固定引用、不重复采集/计算；当前变化只跑必要验证。

完整P5保留当前固定版本回归、单模块隔离及回滚、两连续适用交易日自然接续等原门槛。非每日模块按真实触发合同，不伪造自然运行。
